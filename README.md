# 📊 Data Science Capstone Project

This repository contains my solution to the Data Science Academy capstone project, which includes two major tasks focused on real-world data analysis and machine learning.

---

## ⚡ Task 1: Electricity Contract Optimization

In this task, historical electricity usage data is cleaned and analyzed to determine the most cost-efficient electricity contract among:

- No Flex (fixed price)
- Monthly Flex (monthly variable pricing)
- Hourly Flex (hourly variable pricing)

### Key Steps:
- Data cleaning and preprocessing
- Time-based aggregation (hour, day, month analysis)
- Electricity consumption analysis
- Cost simulation under different contracts

---

## 🚀 Task 2: McKinsey Prohack Challenge

This task focuses on building a predictive and optimization model for an intergalactic dataset.

### Part 1: Prediction
- Regression model to predict a well-being index (`y`)
- Feature engineering and preprocessing
- Model training and evaluation using RMSE

### Part 2: Optimization
- Allocation of limited energy resources under constraints
- Maximization of predicted well-being
- Constraint handling:
  - Total energy = 50000 DSML
  - Max per galaxy = 100 DSML
  - Minimum allocation rules for low-index galaxies
